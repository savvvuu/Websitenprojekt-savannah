# Projektidee
Ich möchte einen Website herstellen, die verschiedene Tiere der Klimazone, die savanne, vorstellen.  
# Zweck
Die Website wird einem etwas über die Klimazone samt 3 Tiere in diesem Lebemsraum erklären. 

# Strucktur und Seitenaufbau
Website über verschiedene Tiere von der selben Klimazone. 
Z.B der Steckbrief von einer Löwe, eines Hyäna und einem Antilopen. 
Auf der Hauptseit wird einen Titel sammt einen kurz Text, beschreibung der Klimazone; z.B die Savanne.Der Hintergrund wird eine gelbliche Farbe haben der das Thema entspricht und wird dann unter der Text zu den Klimazonen Namen der Tiere und unter jeden Namen ein Bild des Tieres. Der Name des Tieres ist aber auch einen Link, der wenn darauf gedrückt, der benutzer zu einer neuen seite hinführt. Da hat es einen Steckbrief
